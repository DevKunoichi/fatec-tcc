## 🖥️ Como Visualizar os Diagramas

Os arquivos `.svg` possuem excelente suporte universal. Você pode:
1. **Abrir no Navegador Web:** Dê um duplo-clique no arquivo ou arraste-o para o Google Chrome, Edge ou Safari para visualizar com zoom infinito sem perda de qualidade.
2. **Inserir em Relatórios Oficiais:** Você pode inserir estes arquivos diretamente no seu documento do Word, Google Docs ou ferramenta LaTeX. A vantagem do SVG é que, ao gerar o PDF final do seu TCC, os diagramas permanecerão em altíssima qualidade (texto nítido e selecionável).

*(Os diagramas foram padronizados para manter uma identidade visual coerente em toda a documentação arquitetural do projeto).*
